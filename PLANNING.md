# Stage 1 - Defining the Project

## What is the project?

This project is meant to be an implementation of the card game Coup. The way that users can play this game is by connecting to a server browser and joining a lobby from that.

## List of Features

This is a list of all features that are to be included in the projects. These have been divided based on what should be on each screen, which the application will switch through. All essential features that are required are **emboldened**. 

- Server Browser
  - Users should be able to connect to a server browser
  - Users should be able to create a lobby from the browser
  - Users should be able to join a lobby from the browser
  - There should be a minimum and maximum player count in the lobby
- Lobby
  - Users should be able to see other players in the lobby
  - Users should be able to set their nickname
- Game
  - **Users should be able to see what cards they have** 
  - **There should be a shared global pot balance**
  - **Users should be able to see their coin balance**
  - Users should be able to see others coin balance
  - Users should be able to see how many cards other people have
  - **Users should be able to submit turns**
  - **Users should be able to block other user's turn**
  - **Blocked users should be able to challenge the block**
  - **Users should be able to challenge other user's turn**
  - **A failed challenge should result in a lost card for the loser**
  - **Users who lose their cards should no longer have a turn**

## What would the MVP include?

The MVP would just include the game screen covering only two aspects, the basic flow of the game and handling multiple connections to the game.
